# Northview College – Website Home Page

## 📌 Project Overview

This project is a simple **College Website Home Page** created using **HTML and CSS**. It represents the official homepage of **Northview College** and is designed to be clean, professional, and student‑friendly.

The webpage includes a header with navigation, an "Explore Our College" section highlighting key areas, and a footer with contact and social media information.

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and layout

---

## 📂 Project Structure

```
Northview-College-Website/
│
├── index.html      # Main homepage file
├── style.css       # Stylesheet for layout and design
├── images/          # Folder for logo and icons (optional)
└── README.md       # Project documentation
```
